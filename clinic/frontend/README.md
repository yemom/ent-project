# clinic Frontend

Modern Next.js frontend for the clinic healthcare clinic management platform.

## Stack

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS
- Shadcn-style component system
- TanStack Query
- Axios
- React Hook Form + Zod
- Zustand
- Framer Motion
- Recharts

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/app` for routing and layouts
- `src/components` for reusable UI and layout primitives
- `src/features` for domain modules
- `src/services` for API clients
- `src/store` for Zustand state
- `src/providers` for app providers
- `src/middleware` for route protection helpers
